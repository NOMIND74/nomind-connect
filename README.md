# NOMIND Connect — свой клиент «как Click Connect», но на своих серверах

Мини-клиент для Windows: выбираете сервер из своего списка, нажимаете «Подключить» — весь
трафик идёт через выбранный сервер, а русские сайты и игры идут напрямую.

Работает на **Xray-core** (тот же движок, что внутри Click Connect), поэтому понимает
VLESS + REALITY, включая XHTTP-узлы, которые Podkop (sing-box) не умеет.

## Как запустить

- Ярлык на рабочем столе: **NOMIND Connect** (иконка — фиолетовая овца с розовым рим-лайтом)
- или файл `NOMINDConnect.cmd` в папке программы

Пока окно открыто — VPN работает. Закрыли окно — Xray гаснет, системный прокси
возвращается в исходное состояние.

## Внешний вид

Тёмный графит с акцентом из трёх цветов: **розовый/неон** (овца, кнопка «Подключить»,
название в шапке), **морской/teal** (проверка, быстрый пинг, состояние «подключено»),
**жёлтый/зелёный/красный** — только для пинга. Контуры кнопок и карточек толстые
(3 px у кнопок, 2 px у карточек), основной фон нейтральный — поэтому интерфейс одинаково
нормально смотрится и у парня, и у девушки, а не «кислотно-розовый».

Шрифт — **Manrope** (лежит в `fonts\`, поэтому выглядит одинаково на любом ПК, ничего
доустанавливать не надо). Список серверов **всегда отсортирован по пингу — от меньшего
к большему**, мёртвые узлы уезжают вниз.

Цвета пинга:

| Пинг | Цвет |
|---|---|
| до 450 мс | зелёный — всё хорошо |
| 450–700 мс | жёлтый — средне |
| больше 700 мс | красный — плохо |
| «не грузит» / «нет» | тёмно-красный, приглушённый, всегда внизу списка |

Полоса прокрутки своя — тонкая, скруглённая, розово-сливовая (не белая системная).
Кнопки — «пилюли» с толстым цветным контуром; «Подключить» светится неоном,
и само название **NOMIND CONNECT** в шапке тоже с неоновым ореолом.

| Цвет | Где используется |
|---|---|
| розовый `#BA5E82` | главная кнопка, активная строка сервера |
| морской `#609A9E` | «Проверить», «Тест», «Из буфера», «Подключено», быстрый пинг |
| жёлтый `#E2BC58` | средний пинг (450–700 мс) |
| красный `#D1565C` | медленный пинг |
| тёмно-красный `#7A4A52` | «не грузит» / «нет» |

## Что умеет

| Кнопка | Что делает |
|---|---|
| **Подключить / Отключить** | запускает/останавливает Xray и включает системный прокси Windows |
| **Проверить все** | проверяет все узлы в фоне: TCP + **реальный запрос страницы** через каждый узел (окно при этом не подвисает) |
| **Тест узла** | быстрая проверка выбранного узла: реальное время ответа и страна выхода |
| **Сервер** | тёмное окно: вставляете `vless://…` — сервер появляется в списке (это один узел) |
| **Подписка** | ссылка подписки (+ необязательный HWID) — все узлы добавляются разом |
| **Удалить** | убрать мёртвый/ненужный узел |

Правая кнопка по серверу — меню: **копировать vless-ссылку**, копировать имя, копировать адрес,
тест узла, удалить. Слева у каждого сервера — флаг страны.

Чем сервер отличается от подписки: **сервер** — это одна конкретная ссылка `vless://`
(один узел, вставляется вручную). **Подписка** — это ссылка от провайдера, по которой
серверов приходит сразу много, и провайдер может их менять.

### Реальный пинг, а не «пинг до порта»

Раньше в списке было время TCP-рукопожатия — узел мог «отвечать 60 мс», а страницы
через него не открывались. Теперь приложение для каждого узла поднимает временный
Xray-конфиг на отдельном порту и **реально скачивает** `https://cp.cloudflare.com/generate_204`
через этот узел:

- число в строке — это полное время запроса через VPN (обычно 350–900 мс);
- если страница не пришла — пишется **«не грузит»** красным;
- TCP-значение показывается приглушённым серым, пока не пришёл реальный результат;
- пороги: ≤450 мс — зелёный, 450–700 мс — жёлтый, больше — красный; «не грузит» — приглушённый тёмно-красный.

Проверка запускается **сама при открытии окна** и повторяется раз в **10 минут**, но идёт
в отдельном процессе — окно не замирает, а строки наполняются по мере ответов. Вручную —
кнопкой «Проверить»; после проверки список один раз пересортировывается по пингу.

### Сайты через VPN

Кнопка «Все сайты…» открывает большое окно (без группировок и счётчиков — просто
один список):

- фильтр по доменам;
- поле ввода: вставляете домен или целую ссылку — приложение сразу подсказывает,
  **нет ли уже похожего** домена в списке, и предлагает готовый бренд;
- подсказки выезжают **отдельной панелью ниже поля поиска** (со своей прокруткой и
  рамкой), поэтому вводимый домен никогда не перекрывают;
- пока печатаете в поле ввода, большой список ниже **фильтруется на лету** — видно только
  подходящие домены; сотрёте текст (передумали добавлять) — вернётся весь список;
- «Из буфера», «Удалить», «Готово»; Del — удалить выбранные, двойной клик — скопировать.

Добавили домен (и на главном экране через поле «+», и в окне «Все сайты…») — если туннель
поднят в режиме «Только выбранные сайты», правила применяются **сразу**: приложение само
перезапускает Xray на тех же портах, а системный прокси не выключается. То есть браузеры,
Discord, Spotify, игры просто переживают короткий (доли секунды) перезапуск ядра — вручную
жать «Отключить/Подключить» больше не нужно. В окне «Все сайты…» повторный запуск делается
один раз, когда закрываете окно кнопкой «Готово».

### Подписки

Кнопка «Подписка» → ссылка вида `https://…/sub/…` и, если панель требует, HWID:

- **HWID** — это номер устройства, который панель подписки запоминает, чтобы считать
  устройства в лимите. Поле можно оставить пустым: приложение само подставляет
  **стабильный HWID этого компьютера** (SHA-256 от `MachineGuid` → формат GUID).
  Он не меняется между запусками и переустановками, поэтому **новое устройство каждый
  раз не регистрируется** и лимит не расходуется. Свой HWID из кабинета можно вписать
  вручную — тогда используется он;
- запрос идёт с `User-Agent: v2raytun/1.0` и заголовком `x-hwid`;
- поддерживаются все три вида ответа панели:
  - **base64** — обычная подписка со списком `vless://`;
  - **plain** — просто строки `vless://`;
  - **JSON-конфиги Xray** — массив объектов с `outbounds` (так отдают Remnawave,
    Marzban и панели на «Happ»): из каждого конфига берётся `vless`-outbound вместе
    с `streamSettings` — REALITY (`pbk`/`sid`/`sni`/`fp`), TLS, WS, gRPC, XHTTP;
- дубликаты по `host:port` пропускаются, счётчик «добавлено / пропущено» пишется в лог;
- если панель вместо серверов вернула **заглушки** (`0.0.0.0:1` с нулевым UUID), они
  не добавляются: появляется окно с объяснением — обычно это занятый лимит устройств,
  нужно сбросить устройства в кабинете/боте или вписать HWID зарегистрированного;
- ссылка и HWID сохраняются в `settings.json` (`subs`, `hwid`);
- подписок можно добавить **сколько угодно** — каждая хранится отдельно, со своим сроком и
  трафиком; в диалоге они показаны списком по 4 строки с прокруткой;
- значок обновления в шапке перезапрашивает все подписки сразу; актуальность видна рядом
  («проверено 5 мин назад»), а дни до окончания — в карточке подписки.

На главном экране серверы **сгруппированы по подписке**: в заголовке группы — сервис
(домен панели) и дата окончания розовым, например `panel.example.com · до 31.12.2026`.
Внутри группы серверы отсортированы по пингу. Клик по заголовку **сворачивает и
разворачивает** группу (шеврон ▸/▾), поэтому длинный список не приходится прокручивать
целиком. Серверы, добавленные вручную, идут отдельной группой «добавлены вручную».

Переключатель маршрутизации:

- **Всё, кроме русских сайтов** — как в Click Connect: **все зарубежные сайты и всё,
  что заблокировано в РФ, идут через VPN**, а русские сайты (`.ru/.su/.рф` и
  `geosite:category-ru`) — напрямую (проверено: в конфиге Xray остаётся финальное
  правило `network: tcp,udp → proxy`, а `ru` перехватывается раньше).
- **Только выбранные сайты** — как Podkop в режиме «список доменов»: через VPN идут
  только домены из списка, остальное напрямую.

Выбранный режим запоминается в `settings.json` и восстанавливается при следующем
запуске. Если переключить карточку при уже поднятом туннеле, программа сама
перезапускает Xray с новым конфигом (в логе — «режим изменён… перезапускаю туннель»),
так что переподключаться вручную не нужно.

Игры (CS2 и другие) идут **напрямую всегда**: они не используют системный прокси,
поэтому пинг не растёт — можно играть и параллельно листать Instagram через VPN.

Галочка «Блокировать рекламу» добавляет правило `geosite:category-ads` → block.

## Защита «нет интернета после выключения ПК»

Главная боль системного прокси: выключили ПК с включённым VPN, включили — прокси
в реестре всё ещё включён, а Xray уже не работает, и интернета нет, пока вручную
не отключишь.

Теперь это лечится автоматически:

- `NOMINDGuard.vbs` прописан в `HKCU\…\Run` (запись «NOMIND Connect Guard»);
- при входе в Windows `NOMINDGuard.ps1` смотрит на состояние:
  - Xray не запущен, а прокси включён → **выключает прокси**, интернет возвращается;
  - Xray запущен, а прокси выключен → включает прокси обратно;
- каждый запуск пишет строку в `runtime\guard.log` (`nothing to do`, `system proxy OFF …`).

Если что-то зависло (например, xray остался висеть после аварийного завершения):

```
powershell -File engine.ps1 -Action reset
```

— гасит xray и выключает системный прокси.

## Где что лежит

```
NOMINDConnect.ps1  окно приложения
NOMINDConnect.vbs  запуск без консоли (на него указывает ярлык)
engine.ps1         движок: сборка конфига, запуск xray, прокси, тесты, подписки
updater.ps1        проверка подписанных обновлений (ECDSA P-256 + SHA-256)
NOMINDGuard.ps1    восстановление прокси при входе в Windows
NOMINDGuard.vbs    тихий запуск guard'а из автозагрузки
release.ps1        сборка и публикация подписанного релиза
version.txt        текущая версия приложения
nomind.ico/.png    иконка и логотип приложения
fonts\             шрифт Manrope (SemiBold / Medium) + Roboto как запасной
bin\xray.exe       ядро Xray + geoip.dat / geosite.dat (скачивается tools\fetch-xray.ps1)
runtime\           рабочий конфиг, логи, pid, update-check.json — создаётся на лету
```

Личные данные — `servers.json`, `settings.json`, `domains.txt`, `runtime\` — в репозиторий
не попадают: они перечислены в `.gitignore`, а `publish.ps1` пускает в коммит только файлы
из явного allowlist. Для примеров в репозитории лежат `servers.sample.json`,
`settings.sample.json` и `domains.sample.txt` (нейтральный список сайтов, который
попадает в установщик вместо личного списка автора).

## Иконка в трее и на панели задач

- На панели задач у окна **иконка приложения** (овечка): в форму ставится `nomind.ico`
  и дублируется в `WM_SETICON` (32×32 и 16×16), поэтому Windows берёт её, а не синюю
  иконку PowerShell.
- В трее рядом с часами — та же иконка (16×16 из `nomind.ico`), с подсказкой
  «NOMIND Connect — VPN включён/выключен».
- Левая кнопка или двойной щелчок по иконке в трее — развернуть окно.
- Правая кнопка — меню: **Открыть окно**, **Подключить/Отключить VPN**,
  **Проверить все серверы**, **Настройки…**, **Проверить обновления…**,
  **Выход (выключить VPN)**.
- Windows 11 по умолчанию прячет новые значки в «^». Если иконки не видно —
  нажмите `^` и перетащите её на панель, Windows запомнит.

## Установка на диск (Setup.exe)

`NOMIND-Connect-Setup.exe` — обычный мастер установки (NSIS):

1. Мастер спрашивает папку; по умолчанию `C:\Program Files\NOMIND Connect`,
   можно указать любой диск (например, `D:\Apps\NOMIND Connect`).
2. Создаёт ярлык на рабочем столе и в меню «Пуск», запись в
   «Программы и компоненты» → «Удалить», прописывает сторожа в автозапуск.
3. Обновление — приложение само тихо проверяет подписанный манифест и **спрашивает
   разрешение**. Только после подтверждения скачивается Setup.exe, проверяется SHA-256
   и запускается установщик (он закрывает старую версию через `NOMINDStop.ps1`).
   Вручную — меню трея «Проверить обновления…».
4. Удаление — «Программы и компоненты» или ярлык «Удалить NOMIND Connect».
   Удалятор сначала снимает системный прокси и гасит Xray (иначе после удаления
   не будет интернета), потом спрашивает, стирать ли данные.

Где лежат данные:

- если папка установки доступна на запись (например, `D:\Apps\...`) — рядом с программой,
  как в портативной версии;
- если папка только для чтения (Program Files) — в `%APPDATA%\NOMIND Connect`
  (`settings.json`, `servers.json`, `domains.txt`, `runtime\`); при первом запуске
  туда копируются серверы и список сайтов.

Пересобрать установщик: `powershell -File build-installer.ps1`
(нужен `makensis.exe`; сборщик берёт версию из `version.txt`, кладёт staging-копию
без логов и личных данных и компилирует `installer\installer.nsi`).

## Обновления и подпись

Версия хранится в `version.txt` — один источник для приложения и установщика.
Релиз собирается и публикуется одной командой:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\release.ps1 -Notes "что нового"
```

Скрипт собирает установщик, считает SHA-256, подписывает манифест `version.json`
ключом ECDSA P-256, коммитит версию через `publish.ps1` и создаёт GitHub Release
с установщиком и манифестом.

- Приватный ключ подписи **не в репозитории**: `%USERPROFILE%\.config\nomind\update-signing-key.bin`,
  защищён DPAPI (только текущий пользователь Windows). Создать: `tools\update-keygen.ps1`.
- В клиенте лежит только публичный ключ. Подпись манифеста проверяется **до** показа
  предложения об обновлении; после скачивания проверяется SHA-256 установщика,
  при несовпадении файл удаляется.
- Установка начинается только после нажатия «Установить». Тихая проверка при запуске
  ничего не устанавливает; отключить её можно в `settings.json` → `"checkUpdates": false`.
- Манифест содержит версию, ссылку, хеш, дату и заметки; подпись покрывает все эти поля,
  поэтому подменить ссылку или хеш без приватного ключа нельзя.

## Перенос на другой компьютер (портативная сборка)
Готовая папка `dist\NOMIND Connect\` (и архив `NOMIND-Connect-portable.zip`) запускается
без установки с флешки или из любой папки:

1. Распаковать **целиком** — `NOMIND Connect.exe` и файлы рядом должны лежать вместе.
2. Запустить `NOMIND Connect.exe` (права администратора не нужны).
3. SmartScreen может сказать «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить всё равно».
4. Используются только файлы из своей папки: `bin\xray.exe`, `servers.json`, `settings.json`,
   `domains.txt`, `runtime\` — реестр и система, кроме системного прокси текущего пользователя,
   не трогаются. Поэтому папку можно просто скопировать другу.
5. `КАК ЗАПУСТИТЬ.txt` внутри папки — короткая инструкция для него же.

При запуске программа сама прописывает сторожа в автозапуск (если рабочей записи ещё нет),
поэтому интернет не пропадёт даже после жёсткого выключения компьютера с включённым VPN.

Пересобрать ярлык-запускалку можно из `NOMINDConnect.vbs`: он запускает
`powershell.exe -File NOMINDConnect.ps1` рядом с собой, без окна консоли.

## Важные ограничения

1. **Системный прокси, без TUN.** Так же, как Click Connect: приложение подменяет
   системный прокси Windows на `127.0.0.1:10809`. Это подхватывают браузеры, Discord,
   Spotify, Telegram, Electron-приложения. Игры и программы, которые лезут в сеть
   «мимо» системного прокси, пойдут напрямую — для игр это то, что нужно.
2. **Прокси действует на текущего пользователя Windows.** Для другого пользователя ПК
   нужно запустить приложение под ним.
3. **Пока окно закрыто — VPN не работает.** Это защита: иначе после закрытия прокси
   остался бы включённым и интернет «пропал» бы. Страхует guard при входе в систему.
4. **Автообновления подписки пока нет.** Кнопка «Подписка» добавляет узлы по ссылке
   вручную; ссылка сохраняется, так что повторный импорт — это один клик.
5. **Жёсткое выключение компьютера.** Системный прокси — это настройка Windows, она
   переживает выключение. Если компьютер выключили (или пропало питание), пока VPN был
   включён, при следующем входе в систему сторож `NOMINDGuard` проверяет, жив ли порт
   Xray, и снимает прокси, если VPN не поднялся — через пару секунд браузеры снова
   работают. Сторож прописывается в автозапуск (`NOMIND Connect Guard` в
   `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) при первом запуске программы.

## Если что-то не открывается

1. Смотрите строку состояния: «подключено» и «выход: … (NL)».
2. Если браузер держит старое соединение — перезапустите его (Chrome подхватывает прокси
   на лету, Firefox — нет).
3. Если у узла «не грузит» — он живой по TCP, но не пропускает трафик: выберите другой.
4. Совсем плохо — закройте окно приложения или выполните `engine.ps1 -Action reset`:
   прокси выключится, интернет вернётся.
